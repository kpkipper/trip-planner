# Modern UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole web app to the fastwork.com-like look in the spec: warm off-white, near-black ink, Anuphan font, dark pill buttons, soft rounded cards, top nav on desktop and a bottom tab bar on mobile.

**Architecture:**
- Design tokens live in `src/app/globals.css` (`@theme`).
- Small presentational building blocks live in `src/components/ui/`. Their class choices sit in pure helpers so they can be unit tested in the node vitest environment.
- Pages switch to the blocks one area at a time.
- No API, routing or data changes, except the new `/trips` page that replaces the sidebar's trip list.

**Tech Stack:** Next.js 16 static export, React 19, TypeScript, Tailwind v4, lucide-react, vitest (node env, `src/**/*.test.ts` only).

**Spec:** `docs/superpowers/specs/2026-11-11-modern-ui-design.md` and mockup `docs/superpowers/specs/2026-11-11-modern-ui-mockup.html`.

## Global Constraints

- **Tokens:** use only these, never new hex values in components.

  | Token | Value |
  |---|---|
  | `bg` | `#f5f5f3` |
  | `surface` | `#ffffff` |
  | `ink` | `#171717` |
  | `ink-2` | `#2b313b` |
  | `muted` | `#646b78` (AA on `bg` and `chip`) |
  | `line` | `rgb(17 17 17 / 0.08)` |
  | `chip` | `#efefec` |
  | `primary` (dark pill) | `#131922` |
  | `primary-hover` | `#2a313c` |
  | `accent` | `#0066cc` |
  | `accent-soft` | `#e8f2ff` |
  | `live` | `#16a34a` (dots and fills) |
  | `live-ink` | `#15803d` (live status as text, AA) |
  | `danger` | `#dc2626` |

  - Radius: `rounded-card` = 24px, `rounded-tile` = 16px, pills = `rounded-full`.
  - Shadow: `shadow-soft` = `0 1px 2px rgb(0 0 0 / 0.04), 0 8px 24px rgb(0 0 0 / 0.06)`.
  - Story ring gradient: `conic-gradient(#f97316, #ec4899, #8b5cf6, #f97316)`.
- **Font:** Anuphan via `next/font/google` (subsets `thai`, `latin`; weights 400, 500, 600, 700) as `--font-sans`. Body uses it.
  - Headings: weight 600, `tracking-tight`.
  - Hero titles: 40–48px desktop, 28–32px mobile.
- **Buttons:** one primary (dark pill) per screen. Secondary is a white pill with a `line` ring. Destructive actions use the `danger` text or fill.
- **Copy and behaviour:** keep all existing copy, labels, aria-labels, routes and behaviour. This is a restyle, not a rewrite. (Spec call: language stays as is this round.)
- **Accessibility must survive:** `useModalA11y` usage, focus rings (`focus-visible:ring-2 ring-accent`), labels, `aria-live` regions.
- Keep the existing story viewer (`moment-lightbox.tsx`) as it is. Only the gallery and entry points around it change.
- **Before each commit:** `pnpm test`, `pnpm lint`, `pnpm exec tsc --noEmit` and `pnpm build` must all pass.
- **Commit messages** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Thai text in pills and chips:** tone marks and upper vowels must not clip. Use line-height ≥ 1.5 and no fixed heights that cut glyphs.
2. **Mobile bottom tab bar:** it must not cover page content, dialogs or the story viewer. Add bottom padding with safe-area, and give it a z-index below dialogs.
3. **Logged-out visitors:** nav shows Trips (the public list at `/trips`) and Log in, no Feed/Requests. (Final review ruling: the public trips list stays reachable.) Create goes to `loginPath('/plans/create')`. Trip pages still work for public trips.
4. **Long titles and names:** truncate or wrap without overflowing cards at 375px.
5. **Trips without cover:** a deterministic gradient from the slug. The same trip always gets the same gradient.
